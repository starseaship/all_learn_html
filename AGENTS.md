# Repository guidance for study materials

When working on Zoe's bilingual study handouts or reading-question HTML pages, follow [the study-html-publish skill](.agents/skills/study-html-publish/SKILL.md).

When working on WGL / Hidden Figures reflections, group-discussion reflections, or required replies to classmates, follow [the WGL reflection-discussion skill](.agents/skills/wgl-reflection-discussion/SKILL.md).

- **Default:** creating or changing this kind of study HTML includes publishing it to the connected GitHub repository `starseaship/all_learn_html`, registering it in `materials.json`, and preserving its labels/metadata in `catalog-overrides.json` unless the user specifically opts out.
- Keep latest-added-first catalog ordering with the existing `addedOrder` metadata; edits do not reset this position.
- Respect the exact focus question numbers and exam notices for each assignment, and preserve mobile-friendly layout, keyword highlights, and per-question Chinese translations.
- Verify completion before reporting that the GitHub version is available.
